# /to-issues project conventions

Populated at project init (via `/grill-with-docs` closing prompts), or auto-populated by `/to-issues` on first invocation if placeholders are still unfilled.

**Note:** `/to-issues` shares conventions with `/to-prd` — at `/grill-with-docs` closing prompts, both files get populated in one shot. Unlike `/to-prd` (which supports local-file destination), `/to-issues` requires a tracker.
